页面布局结构

选择你偏好的整体布局方式

$ whoami
$ cat about.md
$ ls skills/
$ cat contact.json

A. 单页长滚动

一个页面，各板块依次排列，滚动切换。经典简历网站布局，每个区块用 Terminal 命令风格过渡。

~/home
~/about
~/skills
~/work
~/contact
$ cat hero.md
# Hello World
I'm a developer
who builds things

B. 左侧导航 + 右侧内容

左侧 Terminal 风格文件树导航，右侧主内容区。类似 IDE 布局，适合技术感展示。

Tab 1
Tab 2
Tab 3
project_01/
description here
project_02/
description here
project_03/
description here
project_04/
description here

C. 多标签页切换

模拟 Terminal 标签页，点击切换不同板块。每个板块独立展示，有"打开文件"的仪式感。
